# 品达物流 TMS — 技术栈说明

> 本文档记录品达物流 TMS 的**实测技术栈**，并说明与早期 README 的差异。
> 所有结论来自 `pom.xml`、`pd-admin-ui/package.json` 与联调环境 `docker inspect` 实测（2026-10-06）。

---

## 1. 前端技术栈（实测）

| 项目 | 实际 | 早期 README 声称 | 结论 |
|------|------|------------------|------|
| 管理端框架 | **Vue 2.6.10** | Vue3 | ❌ 不符，已决策不迁移 |
| UI 组件库 | **Element UI 2.12.0** | Weex / Vant | ❌ 不符 |
| 图表 | **ECharts 4.2.1** | ECharts | ✅（版本不符） |
| 状态管理 | **Vuex 3.1.0** | — | ✅ |
| 构建工具 | @vue/cli-service 3.5.3（Webpack） | — | ✅ |
| 移动端 | **uni-app（Vue3 + Vite）+ uView-plus + Pinia** | — | 📋 规划中，当前 0 代码 |

> 说明：管理端约 119 个 `.vue` 文件、175 处 `slot-scope`、68 处 `.sync`，迁移 Vue3 成本高且零收益，故锁定 Vue 2.6。

## 3. 中间件与基础设施（实测）

| 组件 | 实际镜像 / 版本 | 端口 | 用途 | 是否必需 |
|------|----------------|------|------|----------|
| MySQL | mysql:5.7（5.7.44） | 3306 | 业务库（按服务分库） | 必需 |
| Redis | redis:5（5.0.14） | 6379 | 验证码 + J2Cache L2 | 必需 |
| Nacos | nacos/nacos-server:1.4.1 | 8848 | 注册 + 配置中心 | 必需 |
| Zookeeper | zookeeper:3.5 | 2181 | Kafka 元数据 | 必需 |
| Kafka | bitnami/kafka:2.6.0 | 9092 | 轨迹消息 | 必需 |
| RabbitMQ | rabbitmq:3.8-management | 5672 / 15672 | 调度事件 | 必需 |
| Seata Server | 1.4.2（宿主 systemd） | 8091 | 分布式事务 TC | 可选（可降级） |

> 网关为 **Zuul 1.x**（`pd-authority/pd-apps/pd-gateway`），入口 `:8760/api`，**非** Spring Cloud Gateway，**无 Sentinel**。

## 4. 与早期 README 的差异（重要）

早期 README 列出了一批**在代码中不存在**的技术组件，本文档已移除或标注为规划：

| 早期 README 声称 | 代码实测 | 处置 |
|------------------|----------|------|
| 前端 Vue3 + Weex + Vant | Vue 2.6 + Element UI | 更正 |
| 网关 Spring Cloud Gateway + Sentinel | Zuul 1.x，无 Sentinel | 更正 |
| MongoDB / HBase / Spark / Hive | 无依赖 | 移除（属路线图，非 bug） |
| RocketMQ | 无依赖（用 RabbitMQ + Kafka） | 移除 |
| SkyWalking / Prometheus / Grafana | 无依赖 / 未接入 | 移除（三期可观测性规划） |
| XXL-JOB | 无依赖（用 Quartz） | 移除 |

> 上述部分组件（如 Prometheus / SkyWalking / ELK）在 [产品差距与商业化升级路线图.html](产品差距与商业化升级路线图.html) 中作为"一期可观测性"规划，但**当前并非项目依赖**，请勿误读为已实现。

## 5. 版本锁死与硬约束

| 约束 | 说明 |
|------|------|
| JDK 1.8 锁死 | Lombok 1.18.x 依赖，升级 JDK 会崩 |
| 不升级依赖 | Spring Boot 2.2.5 / Cloud Hoxton / MyBatis Plus 3.3.0 / Shiro 1.4.0 / Drools 6.5.0 保持 |
| 不引入新中间件 | MongoDB / HBase / ES / RocketMQ / XXL-JOB 等属路线图，非本期 bug |
| 安全 CVE 暂不处理 | FastJSON / Shiro / Spring 已知漏洞当前决策不修复，上线前需重评 |
| MySQL 5.7.44 | 不支持窗口函数（`ROW_NUMBER()` 语法报错），批量脚本需用用户变量 |
| 管理端 Vue 2.6 不迁移 | 迁移成本 2–4 周零收益 |
| 移动端 uni-app（Vue3） | 已定方案 |
