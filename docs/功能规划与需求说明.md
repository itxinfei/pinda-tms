# 品达物流 TMS — 功能规划与需求说明

> 本文档汇总品达物流 TMS 的**功能清单（已实现 / 规划）**、MVP 拆解、合规闸口与明确不做清单。
> 优先级约定：**P0 = MVP 必须（缺则闭环断裂）** / **P1 = 首批迭代** / **P2 = 后续增强** / **三期 = 商业化**。
> 权威输入：[需求文档/需求文档v2_现状梳理与竞品借鉴.md](需求文档/需求文档v2_现状梳理与竞品借鉴.md)（v2.2）、[需求文档/成熟功能整合与落地安排.md](需求文档/成熟功能整合与落地安排.md)（2026-10-07 整合总纲）。

## 2. 已实现功能（✅）

详见 [README.md](../README.md) §4.1 与 [架构设计.md](架构设计.md)。核心已实现能力：

- **订单管理**（`pd-oms`）：12 级状态机、Drools 热加载计费、百度地图解析与距离计算。
- **智能调度**（`pd-dispatch`）：Quartz 多机构独立 cron + 5 阶段流程 + DFS 路径规划（4 种策略）。
- **配送作业**（`pd-work`）：运单（6 状态）/ 运输任务（5 状态）/ 司机作业 / 取派件；乐观锁状态机；末端状态联动回写订单。
- **基础数据**（`pd-base`）：机构、车队、车辆、司机、证照、线路、车次、货物类型、业务范围（地理多边形）。
- **轨迹服务**（`pd-netty`）：Netty TCP + HTTP 双通道，Kafka 异步转发（`tms_order_location`）。
- **权限中心**（`pd-authority`）：RBAC、JWT 网关鉴权、XSS 防护。

## 3. MVP 功能拆解（P0）

> P0 为上线闸口。其中 **3 项合规硬闸口（FR-30/31/36）为上线必要条件**。

### 3.1 管理端核心业务页（6 页，当前 0 页）

| 编号 | 功能 | 页面结构 |
|------|------|----------|
| FR-01 | 订单管理 | 列表（筛选/分页/批量）→ 详情（12 状态时间轴 + 货物 + 操作） |
| FR-02 | 运单管理 | 列表 → 详情（合单/拆单标记） |
| FR-03 | 运输任务看板 | 5 状态列看板 + 途经点 |
| FR-04 | 可视化调度一张图 | 地图 + 待调度订单点 + 可用车辆点 + 派单 |
| FR-05 | 车辆/司机档案 | 列表 + 详情 + 证照到期预警 |
| FR-06 | 在途监控 | 车辆实时位置 + 轨迹回放 + 异常停留/超速 |

### 3.2 三端移动功能（当前 0 代码）

| 编号 | 功能 | 端 |
|------|------|----|
| FR-10 | 登录 + 拦截器（JWT `token`，7200s 无刷新） | 三端共用 |
| FR-11 | 司机端：运输任务、提货/交付 POD（拍照+签名+GPS 水印） | 司机 |
| FR-12 | 司机端：定时轨迹上报（10s）+ 在线状态 | 司机 |
| FR-13 | 快递员端：取派件、**投递方式强制确认**、签收留证 | 快递员 |
| FR-14 | 客户：寄件下单、运费试算、订单查询、轨迹查看 | 客户 |
| FR-15 | 客户：下单前投递偏好采集 | 客户 |
| FR-16 | 客户账户与地址簿建表 | 客户 |
| FR-17 | POD 附件上传落点确认与强关联 | 司机/快递员 |

### 3.3 跨端契约（P0）

| 编号 | 功能 |
|------|------|
| FR-20 | 状态机双向同步桥（司机发车联动 `Order` 23005） |
| FR-21 | 客户按订单号查轨迹（加 `Order.id → transportTaskId` 解析层） |
| FR-22 | 三端共享同一份数据，禁止私存副本 |

### 3.4 合规硬闸口（P0，上线必过）

| 编号 | 功能 | 依据 |
|------|------|------|
| FR-30 | 投递方式确认 + 改投二次确认留痕 | 《快递市场管理办法》 |
| FR-31 | 轨迹真实性校验（时间戳+设备标识+跳变告警） | 交通运输数据规范 |
| FR-36 | 离线/故障车辆禁排班派单 | 《道路运输车辆动态监督管理办法》 |

> 体系化合规（FR-32~35：数据分级 / 单独同意 / 审计 / 存储加密）为 **P1**，不阻断 MVP 上线但需限期补。

## 6. 明确不做（避免范围蔓延）

- ❌ 仓储 WMS（库存/上架/拣货）
- ❌ 外部厂商 API 对接（EDI / 三通一达 / ERP / WMS）
- ❌ 网络货运撮合 / 税务套利
- ❌ 资产管理 / 低值易耗品
- ❌ 双向评价体系
- ❌ **SaaS 化封装（本期/MVP 不做**，多租户 SaaS 属三期商业化再立项）
- ❌ 供应链金融 / ETC / 油卡 / 保险集成（三期再议）
- ❌ 营销优惠券 / 时效产品体系 / 驿站网络
