# 品达TMS 支付与短信真实联调指南

> 说明:本项目已内置完整的渠道适配层(微信支付 APIv3、支付宝 RSA2、短信多平台签名)。
> 默认 `pay.channel=mock`、`sms.active-channel=http` 走模拟/降级通道,可直接联调业务流程;
> 接入真实商户/短信凭据后,按本指南配置环境变量即可切换真实渠道,无需改动代码。

---

## 一、支付渠道配置(微信/支付宝)

### 1. 微信支付(APIv3)

**申请资质**:微信商户平台开通 JSAPI/小程序支付,获取商户号、API 证书、APIv3 密钥。

| 环境变量 | 说明 | 示例 |
|---|---|---|
| `PAY_CHANNEL` | 默认渠道(生产切为 `wechat`) | `wechat` |
| `PAY_WECHAT_APP_ID` | 小程序/公众号 AppID | `wx1234567890abcdef` |
| `PAY_WECHAT_MCH_ID` | 微信支付商户号 | `1900000109` |
| `PAY_WECHAT_API_KEY` | APIv3 密钥(32 位) | `abcdefghijklmnopqrstuvwxyz123456` |
| `PAY_WECHAT_MERCHANT_PRIVATE_KEY` | 商户 API 私钥(PKCS8 PEM,去头尾,base64) | `MIIEvQIBADANBg...` |
| `PAY_WECHAT_MERCHANT_SERIAL_NO` | 商户证书序列号 | `4D9B6D...` |
| `PAY_WECHAT_PLATFORM_PUBLIC_KEY` | 微信平台证书公钥(回调验签用) | `MIIBIjANBg...` |
| `PAY_WECHAT_NOTIFY_URL` | 支付回调地址(经网关) | `https://tms.example.com/api/pay/callback/wechat` |

**流程**:`createPayment` 按 APIv3 签名(商户私钥 SHA256withRSA)统一下单 → 返回 `prepay_id` 供前端拉起支付;
微信异步通知 → `verifyCallback` 用平台公钥验签 + AES-256-GCM 解密 `resource` → 置订单已支付。

### 2. 支付宝(RSA2)

**申请资质**:支付宝开放平台创建网页/手机网站应用,获取 AppId、应用私钥、支付宝公钥。

| 环境变量 | 说明 | 示例 |
|---|---|---|
| `PAY_CHANNEL` | 默认渠道(生产切为 `alipay`) | `alipay` |
| `PAY_ALIPAY_APP_ID` | 开放平台 AppId | `202100215468...` |
| `PAY_ALIPAY_PRIVATE_KEY` | 应用私钥(RSA2,PKCS8,去头尾) | `MIIEvQIBADANBg...` |
| `PAY_ALIPAY_PUBLIC_KEY` | 支付宝公钥(验签用) | `MIIBIjANBg...` |
| `PAY_ALIPAY_RETURN_URL` | 同步跳转地址(可选) | `https://tms.example.com/pay/result` |
| `PAY_ALIPAY_NOTIFY_URL` | 异步通知地址 | `https://tms.example.com/api/pay/callback/alipay` |

**流程**:`createPayment` 组装 `alipay.trade.page.pay` 参数并 RSA2 签名 → 返回签名参数供前端跳转支付宝;
异步通知 → `verifyCallback` 用支付宝公钥验签(剔除 sign/sign_type 后按字典序拼接) + `TRADE_SUCCESS/FINISHED` 校验 → 置订单已支付。

> **安全说明**:渠道未配置商户参数时 `verifyCallback` **fail-closed 拒绝回调**,杜绝伪造支付;已支付幂等、渠道/金额一致性校验在 `PayServiceImpl.handleCallback` 统一执行。

## 二、短信渠道配置(多平台)

### 启用方式
`SMS_CHANNEL` 指定启用渠道: `http` / `aliyun` / `tencent` / `huawei` / `device`。

### 1. 通用 HTTP 网关(默认)
| 环境变量 | 说明 |
|---|---|
| `SMS_CHANNEL` | `http` |
| `SMS_HTTP_URL` | 自建/第三方聚合短信网关 POST JSON 地址(推送 `{mobile, content, time}`) |

### 2. 阿里云短信
| 环境变量 | 说明 |
|---|---|
| `SMS_ALIYUN_ACCESS_KEY_ID` | AccessKeyId |
| `SMS_ALIYUN_ACCESS_KEY_SECRET` | AccessKeySecret |
| `SMS_ALIYUN_SIGN_NAME` | 短信签名(需在阿里云审核通过) |
| `SMS_ALIYUN_TEMPLATE_CODE` | 短信模板 Code |

实现:按阿里云 **RPC 签名规范**(HMAC-SHA1)构造请求调用 `dysmsapi.aliyuncs.com`。

### 3. 腾讯云短信
| 环境变量 | 说明 |
|---|---|
| `SMS_TENCENT_SECRET_ID` | SecretId |
| `SMS_TENCENT_SECRET_KEY` | SecretKey |
| `SMS_TENCENT_SDK_APP_ID` | 短信应用 ID |
| `SMS_TENCENT_SIGN_NAME` | 短信签名 |
| `SMS_TENCENT_TEMPLATE_ID` | 模板 ID |

实现:按腾讯云 **TC3-HMAC-SHA256** 签名规范调用 `sms.tencentcloudapi.com`。

### 4. 华为云短信
| 环境变量 | 说明 |
|---|---|
| `SMS_HUAWEI_APP_KEY` | AppKey |
| `SMS_HUAWEI_APP_SECRET` | AppSecret |
| `SMS_HUAWEI_SIGN_NAME` | 短信签名 |
| `SMS_HUAWEI_TEMPLATE_ID` | 模板 ID |

实现:按华为云 **AK/SK(WSSE)** 签名规范(HMAC-SHA256)调用 `batchSendSms/v1`。

### 5. 通用设备接口(短信猫/短信池)
| 环境变量 | 说明 |
|---|---|
| `SMS_DEVICE_URL` | 设备 HTTP JSON 接口地址 |
| `SMS_DEVICE_TOKEN` | 设备鉴权令牌(可选) |

实现:POST `{mobile, content, timestamp}` + `Authorization: Bearer <token>`。

> **隐私说明**:所有渠道日志均对手机号脱敏(前3后4),未配置凭据时仅记录脱敏手机号,不记录明文内容。

## 三、快速切换示例

```bash
# 本地/演示环境(默认,无需任何凭据)
export PAY_CHANNEL=mock
export SMS_CHANNEL=http

# 生产-微信支付 + 阿里云短信
export PAY_CHANNEL=wechat
export PAY_WECHAT_APP_ID=wx...
export PAY_WECHAT_MCH_ID=1900...
export PAY_WECHAT_API_KEY=...
export PAY_WECHAT_MERCHANT_PRIVATE_KEY=...
export PAY_WECHAT_MERCHANT_SERIAL_NO=...
export PAY_WECHAT_PLATFORM_PUBLIC_KEY=...
export PAY_WECHAT_NOTIFY_URL=https://tms.example.com/api/pay/callback/wechat
export SMS_CHANNEL=aliyun
export SMS_ALIYUN_ACCESS_KEY_ID=...
export SMS_ALIYUN_ACCESS_KEY_SECRET=...
export SMS_ALIYUN_SIGN_NAME=品达物流
export SMS_ALIYUN_TEMPLATE_CODE=SMS_...
```

## 四、注意事项

1. **回调地址必须公网可达**(微信/支付宝异步通知由服务端回调),且需配置为网关路由 `/api/pay/callback/**`;
2. **证书/私钥不要提交到仓库**:通过环境变量注入,仓库内 `.env` 已加入 `.gitignore`;
3. **正式切换前建议**:先在沙箱/测试环境验证验签与回调,再切换 `PAY_CHANNEL`/`SMS_CHANNEL`;
4. 短信模板参数与各平台变量占位符需按模板定义对齐(内容以 `content` 参数传入模板变量)。
