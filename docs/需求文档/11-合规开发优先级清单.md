# 合规开发优先级清单（排期依据）

> 文档定位：基于《10-物流行业合规与监管要求.md》的 19 项待补需求，转化为**可排期的开发优先级清单**，作为 PM 排期、开发落地、上线合规闸口的依据。
> 配套文档：《10-物流行业合规与监管要求.md》（法规→需求映射）、各端任务卡（落地位置）、联调就绪检查清单（上线判定）。
> 硬约束沿用：JDK 1.8 不升级、不引新中间件（数据治理用现有 pd-base/pd-user + 网关鉴权扩展）、不对接外部厂商 API、边界条款（网络货运撮合/税务、危货）不实现。
