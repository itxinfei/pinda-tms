## 〇、开发前置约定（所有页面通用）

1. **请求封装**：统一走 `src/utils/request`（Axios），`baseURL = /api`，自动注入 `token` 头；`code!==0` 视为失败；401 清 token 跳登录（无刷新）。禁止裸 `fetch` 直连（ofpay/customer 旧实现需整改）。
2. **设计 Token（✅ 已定案 2026-10-07，见《14-管理端UI规范与页面模板.md》索引第 34 条）**：管理端新增 `src/styles/tokens.scss` + `element-variables.scss`，**品牌主色统一 `#2B6CFF`**（与移动端同一品牌色；**废弃** `#1890ff`/`#E05635`/`#409EFF` 三处冲突色，证据见管理端现状页面审计），所有色值/间距/字号走变量，**禁止页面内硬编码 hex**；页面模板/图表/地图/禁止清单/DoD 均以该规范为准。
3. **分页参数**：多数接口用 `page` + `pagesize`；注意 `pd-web-customer` 地址簿用 `pageSize`（驼峰）——但本卡均为 `/api/web-manager`，统一用 `pagesize`（小写）。
4. **地图能力（✅ 技术选型已锁定 2026-10-06，但依赖尚未落地）**：在途监控/调度一张图采用**百度地图 JS API GL**。理由：后端轨迹存库即百度 BD-09（消费侧已在 pd-netty 把 GPS 原始坐标统一转 BD-09），**前端零坐标转换**。**现状（2026-10-07 核实）**：`package.json` 的 dependencies **未引入** `vue-baidu-map-3x`，`public/index.html` 也**未引** GL JS 脚本（仅有百度统计 `hm.js`），src 下**暂无**地图 ak 配置项——落地本页时须二选一新增依赖或在 `index.html` 注入 GL JS 脚本，并配置真实百度 ak（开发期可用测试 key 或 mock 数据先行）。移动端小程序侧用腾讯地图（GCJ-02）不受影响。
5. **复用现有组件**：列表用 `el-table` + `el-pagination`；表单用 `el-form` + `el-dialog`；下拉用 `el-select`（数据源走 `CommonController` 的 `common/*/simple`）。
6. **菜单登记（静态直出方案的必做动作）**：每建一个业务页，除创建 `@/views/${path}.vue` 外，**必须把对应菜单项加入 `src/router/menu.js` 的 `staticMenu`**（含 `path`/`name`/`component`/`meta`），否则侧边栏不显示入口。注意 `staticMenu` 当前开发测试环境**不按角色过滤、固定全量**；生产环境若需按角色 RBAC，需另行改回动态拉取（见 `menu.js` 头部注释）。后端 `pd_auth_resource` 注册仍不可少，但它只决定**网关鉴权放行**，不再决定菜单显示。

|---|---|---|
| POST | `/api/web-manager/notify/page` | 通知记录分页（业务类型/接收人/通道/状态） |
| POST | `/api/web-manager/notify/send` | 手动补发通知（选单号 + 模板） |
| GET | `/api/web-manager/notify/template/page` | 通知模板管理（短信正文/微信模板 id） |
| POST | `/api/web-manager/notify/rule` | 通知规则配置（哪些告警/节点 → 哪些人 → 哪个通道） |

- **触发场景（P1，随告警中心前端先行）**：告警生成（OPS-0 `pd_transport_alert`）→ 按规则推送；业务节点（下单/揽收/装车/发车/到达/派送/签收）→ 推客户/司机/快递员。
- **通道（P1 只做短信，微信模板预留）**：短信复用管理端既有"短信任务/模板"页面通道（`EntCoordSyncJob` 同款 `HttpURLConnection`，不引新依赖）；微信模板消息留 `notify/rule` 通道字段（`channel=wx_template`），后端不实现，前端不展示入口。
- **留痕**：通知记录落库（`pd_notify_record`，pd-work 库），纳入审计（R6-3 查询留痕）。
- ⚠️ 上述接口同须注册 `pd_auth_resource` 并绑定菜单角色（阻断 C）。
- **前端**：管理端"通知中心"页（`pinda/notify/index`，P1 与告警中心同批）；客户/司机/快递员端订阅展示（移动端任务卡对应页面补通知入口，P1 轮询拉取，不做推送 SDK）。
