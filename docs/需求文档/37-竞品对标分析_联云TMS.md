## 二、已确定缺失的8 项功能（成熟 TMS 必备，我方 SRS 无）

> 判断依据：这些是联云作为**成熟商业 TMS** 的公开必备功能，且与我方已有功能强相关（补上不增加新系统边界）。

###缺口1：车辆/证件合规到期提醒 🔴
- **联云**：车辆行驶证、道路运输证、司机驾驶证、从业资格证**到期前自动提醒**，确保合规上路。
- **我方现状**：`BASE-02 司机管理`只写"司机档案、资质、状态"，**无到期提醒**；SRS 全文 "证件到期" **0 命中**。
- **确定性判断**：✅ **确定需求**。合规是TMS 刚需，我方 §10 DoD 与红线第 17 条已强调脱敏/留痕，证件到期属同一风险面。
- **建议**：新增 `CMP 合规提醒域`（CMP-01 证件到期提醒 / CMP-02 违章记录）。

### 缺口 2：违章记录管理
- **联云**：管理后台含"违章记录"。
- **我方**：全文 "违章" **0 命中**。
- **建议**：并入 CMP-02，与证件提醒同域。

### 缺口 3：路费/过路过桥费/装卸费 **分项计费**
- **联云**：明确列出"**过路过桥费、等待费、装卸费、超重附加费**"等多种费用项，自动汇总与运单挂钩。
- **我方现状**：`POD-03 附加费`只含 **燃油/等待/返空**——**缺路费、过路过桥费、装卸费、超重附加费**。
- **确定性判断**：✅ **确定需求**。这是运费构成的完整性问题（我方 RPT-01 成本里已有"路费"，但**计费侧 POD-03 没有对应费用项** → 两侧口径不一致，会导致成本项无法从运费侧归集）。
- **建议**：扩充 POD-03 费用项清单为：路费 + 过路过桥费 + 等待费 + 装卸费 + 超重附加费 + 燃油附加费 + 返空费。

### 缺口 4：超重附加费
- 同上，联云明确列 "超重附加费"。我方 SRS "超重" **0 命中**。
- 并入 POD-03。

### 缺口 5：车辆利用率（空载率/有效里程）
- **联云**：统计每辆车**有效运营里程、空载率、维修频次**，优化车队配置。
- **我方**：全文 "空载率" "空驶" **均 0 命中**；`DSP-04 智能配载`只提"配载率"，未提"空驶率优化"。
- **确定性判断**：✅ **确定需求**（降本核心指标，联云宣称"削减10% 用车成本"靠它）。
- **建议**：新增 `RPT-06 车辆利用率`（有效里程/空载率/维修频次）。

### 缺口 6：应急处置（突发事件车辆定位）
- **联云**：突发事件**快速定位车辆位置与当前装载货物信息**，支持远程协助指挥与现场上报。
- **我方**：全文 "应急" **0 命中**。
- **确定性判断**：🟡 **较确定**（安全合规相关），但优先级取决于是否要做应急场景。
- **建议**：并入 `MON监控运维域`（MON-04 应急处置）。

### 缺口 7：零担拼车自动拆分运费
- **联云**：零担计费"支持多客户**货物拼车**，自动按比例拆分运费"。
- **我方现状**：`ORD-05 运单拆分/合并`是**运单维度**的拆合单；`POD-03` 计费方式含"零担"，但**无"拼车按比例拆分运费"**这条计费规则。
- **确定性判断**：✅ **确定需求**（零担模式核心计费能力）。
- **建议**：POD-03 补"零担拼车按体积/重量比例拆分运费"规则。

### 缺口 8：客户价值评估
- **联云**：统计各客户**运单量、回款周期、投诉率**，识别优质/高风险客户。
- **我方**：全文 "客户价值" **0 命中**；`PER-01 绩效考核`只做司机/承运商KPI，**无客户维度**。
- **确定性判断**：🟡 **较确定**（我方 RPT-04 已有"账期回款+逾期"，但无客户价值汇总视图）。
- **建议**：并入 `RPT 报表成本域`（RPT-07 客户价值评估）。
