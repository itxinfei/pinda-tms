# 核心业务页面设计示例（大模型专用）

> **目的**：给大模型提供**具体业务页面的完整设计示例**，让大模型开发时直接复制对应页面的模板，只改业务字段和接口调用，不要自由发挥。
> **配套文档**：《38-管理端页面开发指南_大模型专用.md》（通用骨架）、《14-管理端UI规范与页面模板.md》（设计 Token）
> **强制力**：所有核心业务页必须套用本文档的对应模板，禁止从零设计 UI。

---

## 〇、使用说明

1. **先选模板**：开发哪个页面，就复制本文档对应的模板
2. **再改业务**：只改字段名、接口地址、业务逻辑，不改布局结构和样式
3. **最后验证**：写完后对照《38-管理端页面开发指南》的检查清单逐项核对

## 一、订单列表页（P0 · 最常用的列表页）

### 1.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  订单管理                                    [批量导入] [新建订单] │
├─────────────────────────────────────────────────────────────┤
│  ┌─ 筛选区 ──────────────────────────────────────────────┐ │
│  │ 订单号: [____]  客户: [____]  状态: [下拉▼]  日期: [📅] │ │
│  │                              [查询] [重置]             │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ 表格区 ───────────────────────────────────────────────┐ │
│  │ 订单号 │ 客户 │ 寄件人 │ 收件人 │ 状态 │ 金额 │ 操作    │ │
│  │ ORD001 │ 张三 │ 李明   │ 王芳   │ 运输中│ ¥500 │ 详情 编辑│ │
│  │ ORD002 │ 李四 │ 赵六   │ 钱七   │ 待取件│ ¥300 │ 详情 编辑│ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ 分页 ────────────────────────────────────────────────┐ │
│  │ 共 128 条  < 1 2 3 ... 13 >  10条/页 ▼               │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 设计要点

- **筛选区**：常用筛选条件横向排列，不超过 5 个，多余的收进"更多筛选"
- **表格列**：订单号（固定左）、客户、寄件人、收件人、状态（标签）、金额（右对齐）、操作（固定右）
- **状态标签**：待取件/已取件待发货=warning、运输中/派送中=primary、已签收=success、已拒收=danger、已取消=info
- **操作按钮**：详情（主操作）、编辑（次操作），用 link 类型按钮

### 2.2 设计要点

- **卡片式布局**：每个信息区块一个卡片，从上到下依次排列
- **基本信息**：最显眼的位置，展示订单号、状态、金额
- **收发货信息**：左右两栏对比展示
- **货物明细**：表格形式，可编辑可删除
- **物流轨迹**：时间轴形式，已完成的用实心点，未完成的用空心点

## 九、常见错误对照表

| 错误 | 正确做法 |
|---|---|
| 页面里手写 `<div style="...">` 做布局 | 用 `el-row` / `el-col` / `el-card` 组件 |
| 硬编码颜色值（如 `#1890ff`） | 用设计 Token 变量（如 `var(--c-primary)`） |
| 列表页不用分页组件 | 必须用 `el-pagination`，每页 10/20/50/100 条可选 |
| 状态直接显示数字 | 用 `el-tag` 标签展示，不同状态不同颜色 |
| 没有加载状态 | 表格必须加 `v-loading` |
| 没有空状态 | 列表为空时显示 `el-empty` |
| 弹窗宽度写死（如 `width="800px"`） | 根据内容调整，表单弹窗一般 500-600px |
| 操作按钮用普通按钮 | 用 `link` 类型按钮，节省空间 |
