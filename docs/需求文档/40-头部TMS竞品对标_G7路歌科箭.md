# 头部 TMS 竞品对标分析（G7易流 / 路歌 / 科箭）

> **对标日期**：2026-10-08
> **对标对象**：G7易流、路歌、科箭 三家头部 TMS 产品
> **目的**：识别成熟 TMS 的必备功能，对照品达 TMS 的现状，找出可以借鉴的功能点
> **信息来源**：各公司官网 + 公开案例 + 行业报告

---

## 〇、对标结论速览

| 结论 | 内容 |
|---|---|
| ✅ **三家共同的核心功能** | 订单管理 / 调度派车 / 在途跟踪 / 电子回单 / 运费结算 / 司机 APP |
| 🔶 **品达已有但需加强** | 调度算法、财务对账、承运商管理、异常告警 |
| ❌ **品达缺失或薄弱** | IoT 硬件集成、AI 安全风控、智能配载优化、自动化计费引擎、多租户 SaaS |
| 💡 **可以借鉴的特色功能** | 路歌的车货匹配、G7 的 IoT 安全管家、科箭的仓配一体化 |

---

## 一、三家产品定位对比

| 维度 | G7易流 | 路歌 | 科箭 | 品达 TMS |
|---|---|---|---|---|
| **定位** | IoT + 运输管理（软硬一体） | 全链路数字货运平台 | 供应链 SaaS 云平台（OMS+WMS+TMS） | 自营/加盟运输管理 TMS |
| **核心卖点** | 车载 IoT 终端 + AI 安全风控 | 车货匹配 + 司机社区（卡友地带） | 智能配载 + 自动化计费 + 快速上线 | 开源可商用 + 三端齐全 + 性价比 |
| **客户群** | 货主企业、货运经营者 | 物流公司、货主企业、个体司机 | 制造、零售消费品、综合物流 | 中小自营车队、区域 3PL |
| **收费模式** | SaaS 订阅 + 硬件销售 + 交易抽佣 | 平台交易抽佣 + SaaS 订阅 | SaaS 订阅（按模块/用户数） | 开源免费 + 商业版授权 |
| **价格区间** | 10-100 万/年 | 5-50 万/年 | 20-200 万/年 | 核心免费 + 商业版 5-30 万/年 |

## 二、G7易流 功能对标

### 2.1 核心功能清单

| 功能模块 | 具体功能 | 品达现状 | 差距评估 |
|---|---|---|---|
| **车队管理** | 车辆档案、司机档案、车辆维修保养、保险管理 | 🔶 部分（有车辆/司机档案，缺维修保养/保险） | P1 可补 |
| **在途监控** | 实时定位、轨迹回放、电子围栏、偏航告警 | ✅ 已有（百度地图 + GPS 定位） | 基本对齐 |
| **安全管理** | AI 驾驶行为分析、疲劳驾驶预警、超速告警、路线风险预警 | ❌ 缺失 | P2（依赖硬件） |
| **数字货运** | 车货匹配、在线支付、电子回单、运费结算 | 🔶 部分（有运费结算，缺车货匹配/在线支付） | P2（车货匹配） |
| **数字能源** | 加油管理、ETC 管理、充电管理、油耗分析 | 🔶 部分（有油耗记录，缺加油/ETC/充电集成） | P1 可补 |
| **冷链管理** | 温度实时监控、超标告警、温度日志 | ❌ 缺失（已明确不做） | P2（按需） |
| **智能装备** | 车载终端、温感设备、视频监控 | ❌ 缺失（软件侧可做管理界面） | P2（依赖硬件） |
| **物联保险** | 货物保险、车辆保险、司机保险 | ❌ 缺失 | P2（依赖外部合作） |

### 2.2 G7 的特色功能（值得借鉴）

| 特色功能 | 说明 | 品达可借鉴吗？ |
|---|---|---|
| **AI 安全管家** | 通过车载终端采集驾驶行为数据，AI 分析风险（急加速/急刹车/疲劳驾驶），实时告警 | 🔶 软件侧可做告警管理界面，硬件侧 P2 再考虑 |
| **财运通** | 管车 + 管账一体化，车辆位置 + 费用数据全链条贯通 | ✅ 可借鉴，把车辆管理和费用管理打通 |
| **合同可视化** | 运输合同执行进度可视化，上下游共享数据 | ✅ 可借鉴，订单详情页展示合同信息 |
| **物联保险** | 基于 IoT 数据的保险定价和理赔 | ❌ 不做（依赖保险公司合作） |

## 五、对标结论与建议

### 5.1 三家都有、品达也有的（基本对齐）
- ✅ 订单管理 / 运单管理
- ✅ 调度派车 / 在途跟踪
- ✅ 电子回单 / POD 签收
- ✅ 司机端 APP / 客户端小程序
- ✅ 车辆/司机档案管理

### 5.2 三家都有、品达薄弱的（P1 可补）
| 功能 | 优先级 | 建议 |
|---|---|---|
| 智能配载推荐 | P1 | 做规则版（基于体积/重量/线路推荐车型），AI 优化 P2 |
| 自动化计费/对账 | P1 | 完善 Drools 运费规则引擎，支持多维度对账 |
| 承运商 KPI 考核 | P1 | 增加承运商档案、考核指标、评级管理 |
| 油耗/费用分析 | P1 | 增加油耗统计、成本分析、趟次利润报表 |
| KPI 运营看板 | P1 | 增加运营数据大屏（订单量/准时率/异常率） |

### 5.3 三家有、品达没有的（P2 按需）
| 功能 | 优先级 | 建议 |
|---|---|---|
| IoT 硬件集成 | P2 | 软件侧做管理界面，硬件接入后续按需 |
| AI 安全风控 | P2 | 依赖车载终端，P2 再考虑 |
| 冷链温控 | P2 | 软件侧做温度监控界面，硬件接入后续按需 |
| WMS 仓储 | P2 | 按需另立项 |
| 多租户 SaaS | P2 | 商业版功能 |

### 5.4 品达独有优势（继续保持）
- ✅ **开源可商用**：核心代码 Apache 2.0 开源，客户可以自己二开
- ✅ **三端齐全**：司机端 + 快递员端 + 客户小程序 + 管理端，全链路闭环
- ✅ **性价比高**：远低于头部厂商的价格
- ✅ **自主可控**：客户可以自己部署在自己的服务器上

## 六、建议补充的功能（按优先级）

### P1（第一批迭代补齐）
1. **智能配载推荐**：基于货物体积/重量/线路，自动推荐最优车型和配载方案
2. **油耗/成本分析**：增加油耗统计、趟次成本、利润分析报表
3. **承运商 KPI 管理**：承运商档案、考核指标、评级、结算管理
4. **运营数据看板**：管理端首页增加 KPI 大屏（订单量/准时率/异常率/车辆利用率）
5. **运费审批流程**：运费申请 → 调度审核 → 财务审批 → 打款，全流程线上化

### P2（后续按需补充）
1. **IoT 设备管理**：温感/GPS/视频设备接入管理界面
2. **冷链温控监控**：温度实时监控、超标告警、温度日志
3. **WMS 仓储管理**：轻量仓储管理模块
4. **月台预约管理**：仓库出入园预约、码头管理
5. **多租户架构**：商业版多租户 SaaS 功能
