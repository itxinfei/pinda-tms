# 移动端核心页面设计示例（大模型专用）

> **目的**：给大模型提供**移动端三端（司机端/快递员端/客户端）具体业务页面的完整设计示例**，让大模型开发时直接复制对应页面的模板，只改业务字段和接口调用，不要自由发挥。
> **配套文档**：《13-UI设计规范与页面模板.md》（设计 Token）、《39-核心业务页面设计示例_大模型专用.md》（管理端示例）
> **技术栈**：uni-app + Vue3 + uview-plus
> **强制力**：所有移动端核心页面必须套用本文档的对应模板，禁止从零设计 UI。

---

## 〇、使用说明

1. **先选模板**：开发哪个端的哪个页面，就复制本文档对应的模板
2. **再改业务**：只改字段名、接口地址、业务逻辑，不改布局结构和样式
3. **最后验证**：写完后对照《13-UI设计规范》的检查清单逐项核对

#### 设计要点

- **底部 Tab**：首页 / 任务 / 我的（三个 tab）

#### 完整代码模板

```vue
<template>
  <view class="page">
    <!-- 顶部导航栏 -->
    <u-navbar title="任务列表" :auto-back="false" bg-color="#2B6CFF" title-color="#fff" />

    <!-- 状态 Tab -->
    <u-sticky>
      <view class="tabs">
        <u-tabs :list="tabList" :current="currentTab" @change="handleTabChange" line-color="#2B6CFF" />
      </view>
    </u-sticky>

    <!-- 任务列表 -->
    <view class="task-list">
      <u-loadmore :status="loadStatus" />
      <template v-if="taskList.length > 0">
        <view
          v-for="(item, index) in taskList"
          :key="index"
          class="task-card"
          @click="handleTaskClick(item)"
        >
          <view class="card-header">
            <text class="task-id">{{ item.id }}</text>
            <u-tag :type="statusTagType(item.status)" size="mini">{{ statusText(item.status) }}</u-tag>
          </view>
          <view class="card-body">
            <view class="route">
              <text class="city">{{ item.startCity }}</text>
              <text class="arrow">→</text>
              <text class="city">{{ item.endCity }}</text>
            </view>
            <view class="cargo">
              <text class="cargo-info">{{ item.goodsName }} · {{ item.weight }}吨</text>
            </view>
            <view class="time">
              <text class="time-text">预计到达: {{ item.expectArriveTime }}</text>
            </view>
          </view>
        </view>
      </template>
      <!-- 空状态 -->
      <u-empty v-else-if="loadStatus === 'nomore'" text="暂无任务" />
    </view>

    <!-- 底部 Tab -->
    <u-tabbar :list="tabbarList" :current="currentTabbar" @change="handleTabbarChange" />
  </view>
</template>

<script setup>
import { ref, onMounted } from 'vue'

// ============ 状态定义 ============
const currentTab = ref(0)
const loadStatus = ref('loadmore')
const taskList = ref([])

// ============ Tab 配置 ============
const tabList = ref([
  { name: '全部' },
  { name: '待装车' },
  { name: '运输中' },
  { name: '已完成' },
])

// ============ 底部 Tab 配置 ============
const tabbarList = ref([
  { iconPath: '/static/tabbar/home.png', selectedIconPath: '/static/tabbar/home-active.png', text: '首页' },
  { iconPath: '/static/tabbar/task.png', selectedIconPath: '/static/tabbar/task-active.png', text: '任务' },
  { iconPath: '/static/tabbar/user.png', selectedIconPath: '/static/tabbar/user-active.png', text: '我的' },
])
const currentTabbar = ref(1)

// ============ 状态映射 ============
const statusTagType = (status) => {
  const map = {
    1: 'warning',    // 待装车
    2: 'primary',   // 运输中
    3: 'success',   // 已完成
  }
  return map[status] || 'info'
}

const statusText = (status) => {
  const map = {
    1: '待装车',
    2: '运输中',
    3: '已完成',
  }
  return map[status] || '未知'
}

// ============ 方法 ============
const handleTabChange = (index) => {
  currentTab.value = index
  loadTaskList()
}

const loadTaskList = async () => {
  loadStatus.value = 'loading'
  try {
    // TODO: 调用接口
    // const res = await getTaskList({ status: currentTab.value })
    // taskList.value = res.data
    loadStatus.value = 'nomore'
  } catch (error) {
    loadStatus.value = 'loadmore'
  }
}

const handleTaskClick = (item) => {
  uni.navigateTo({ url: `/pages/task/detail?id=${item.id}` })
}

const handleTabbarChange = (index) => {
  currentTabbar.value = index
  if (index === 0) {
    uni.switchTab({ url: '/pages/home/index' })
  } else if (index === 2) {
    uni.switchTab({ url: '/pages/user/index' })
  }
}

onMounted(() => {
  loadTaskList()
})
</script>

<style scoped>

  background-color: #F5F6F8;
}

.tabs {
  background-color: #fff;
}

}

  padding: 24rpx;
```

## 四、常见错误对照表

| 错误 | 正确做法 |
|---|---|
| 页面里手写 `<div style="...">` 做布局 | 用 `view` + uview-plus 组件 |
| 硬编码颜色值（如 `#1890ff`） | 用设计 Token 变量（如 `var(--c-primary)`） |
| 按钮太小不方便点击 | 司机端按钮高度 ≥ 88rpx，方便单手操作 |
| 没有加载状态 | 列表必须加 `u-loading-page` 或 `v-loading` |
| 没有空状态 | 列表为空时显示 `u-empty` |
| 文字太小看不清 | 正文字号 ≥ 28rpx，司机端阳光下可读 |
| 操作按钮太多太杂 | 按状态显示，一次只显示 1-2 个主操作 |
| 底部没有固定操作栏 | 重要操作放底部固定操作栏，方便点击 |
