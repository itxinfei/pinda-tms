# 前端页面接口对接清单（大模型专用）

> **目的**：按"页面→接口"的方式整理，让大模型开发时直接查这个清单，不要瞎编接口路径。
> **配套文档**：《08-后端接口文档.md》（完整接口清单）、《39-核心业务页面设计示例_大模型专用.md》（管理端页面）、《42-移动端核心页面设计示例_大模型专用.md》（移动端页面）
> **强制力**：前端开发时必须按本文档的接口路径调用，禁止自己编接口路径。

---

## 〇、全局约定（所有页面通用）

| 项 | 约定 |
|---|---|
| **基础路径** | `http://192.168.20.130:8760/api`（开发环境） |
| **请求头** | `token: <JWT>`（登录后从 localStorage 取） |
| **成功码** | `code === 0`（数字，不是字符串 "00000"） |
| **失败处理** | `code !== 0` 时弹错误提示；`code === 401` 时清 token 跳登录 |
| **分页参数** | `pageNum`（页码，从 1 开始）+ `pageSize`（每页条数） |
| **分页返回** | `{ list: [], total: 100, pageNum: 1, pageSize: 10 }` |

## 一、管理端页面接口清单

### 1.1 登录页

| 功能 | 接口路径 | 方法 | 参数 | 返回示例 |
|---|---|---|---|---|
| 获取验证码 | `/authority/anno/captcha?key={key}` | GET | key（时间戳随机串） | 直接返回 PNG 图片流 |
| 登录 | `/authority/anno/login` | POST | `{ username, password, key, captcha }` | `{ code: 0, data: { token: "xxx", user: {...} } }` |

**注意事项**：
- 验证码接口直接返回图片，前端用 `<img :src="url">` 展示
- key 是前端生成的随机串，登录时和验证码一起传给后端
- 登录成功后，token 存 localStorage，后续请求都带上

## 四、常见错误对照

| 错误 | 正确做法 |
|---|---|
| 接口路径写错（如 `/api/order/list`） | 管理端是 `/api/web-manager/order-manager/order/page` |
| 请求头用 `Authorization: Bearer xxx` | 用 `token: xxx` |
| 成功判断用 `code === "00000"` | 用 `code === 0`（数字） |
| 分页参数用 `page` + `size` | 用 `pageNum` + `pageSize` |
| 直接调用内部服务接口（如 `/api/pd-oms/order/list`） | 内部服务不暴露网关，必须走 `/api/web-manager/` 聚合层 |
| 轨迹接口带 token | 轨迹接口免鉴权，不用带 token |
| 401 错误后静默刷新 token | 没有 refreshToken，401 直接跳登录页 |
