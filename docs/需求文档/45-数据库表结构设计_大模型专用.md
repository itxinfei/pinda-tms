### 3.1 P1-13 证件到期提醒

**不需要新建表**，在现有表里加字段即可：

```sql

ALTER TABLE `pd_truck_license` ADD COLUMN `last_remind_time` DATETIME NULL COMMENT '上次提醒时间';

-- pd_truck_driver_license 加提醒字段
ALTER TABLE `pd_truck_driver_license` ADD COLUMN `remind_status` TINYINT(4) DEFAULT 0 COMMENT '提醒状态: 0-未提醒 1-已提醒';
ALTER TABLE `pd_truck_driver_license` ADD COLUMN `last_remind_time` DATETIME NULL COMMENT '上次提醒时间';
```

### 3.2 P1-14 费用项扩充

新增费用项：

### 3.3 P1-15 车辆利用率统计

**不需要新建表**，通过查询计算即可：
- 有效运营里程 = SUM(pd_task_transport.actual_distance)
- 空载率 = 空载趟次数 / 总趟次数
- 维修频次 = COUNT(pd_truck_license 维修记录)

### 3.4 P1-16 零担拼车拆分运费

**新建表**：

```sql
CREATE TABLE IF NOT EXISTS `pd_freight_split` (
  `id`                 VARCHAR(64)    NOT NULL                COMMENT '主键',
  `transport_order_id` VARCHAR(64)    NOT NULL                COMMENT '运单id',
  `order_id`           VARCHAR(64)    NOT NULL                COMMENT '订单id',
  `split_ratio`        DECIMAL(8,4)   NOT NULL DEFAULT 0.0000 COMMENT '拆分比例（按体积或重量）',
  `amount`             DECIMAL(14,2)  NOT NULL DEFAULT 0.00   COMMENT '拆分金额',
  `create_time`        DATETIME       NOT NULL                COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_transport_order` (`transport_order_id`),
  KEY `idx_order` (`order_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='零担拼车运费拆分';
```
