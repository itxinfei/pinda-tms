## 一、在途监控地图页（管理端）

### 1.1 页面定位

- **路径**：`/monitor/realtime`
- **功能**：实时展示所有在途车辆的位置、状态、关联订单
- **用户**：调度员、运营人员

### 1.2 布局设计

```
┌─────────────────────────────────────────────────────────┐
│ 顶部工具栏：筛选条件 + 刷新按钮                          │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│  左侧列表    │            地图区域                     │
│  （车辆/订单） │        （占 70% 宽度）                  │
│  （30% 宽度） │                                          │
│              │                                          │
│              │                                          │
├──────────────┴──────────────────────────────────────────┤
│ 底部信息栏：选中车辆/订单的详情卡片                      │
└─────────────────────────────────────────────────────────┘
```

### 1.3 技术选型

| 技术 | 选型 | 说明 |
|---|---|---|
| 地图库 | 百度地图 JS API GL | 后端统一存储 WGS84，显示层做 WGS84→BD-09 转换（口径见 BA-19） |
| 轮询 | setInterval 5秒 | 每5秒刷新一次车辆位置 |
| 状态颜色 | 4色编码 | 待调度=灰色、在途=绿色、异常=红色、已到达=蓝色 |

### 1.4 完整代码模板

```vue
<template>
  <div class="page-monitor">
    <!-- 顶部工具栏 -->
    <div class="toolbar">
      <el-select v-model="filterStatus" placeholder="状态筛选" clearable>
        <el-option label="全部" value="" />
        <el-option label="待调度" value="0" />
        <el-option label="在途" value="1" />
        <el-option label="异常" value="2" />
      </el-select>
      <el-button type="primary" @click="refresh">刷新</el-button>
    </div>

    <!-- 主内容区 -->
    <div class="main-content">
      <!-- 左侧列表 -->
      <div class="sidebar">
        <el-table :data="truckList" @row-click="selectTruck" highlight-current-row>
          <el-table-column prop="truckNo" label="车牌号" />
          <el-table-column prop="driverName" label="司机" />
          <el-table-column prop="status" label="状态">
            <template #default="{ row }">
              <el-tag :type="statusTagType(row.status)">{{ statusText(row.status) }}</el-tag>
            </template>
          </el-table-column>
        </el-table>
      </div>

      <!-- 地图区域 -->
      <div class="map-container" ref="mapContainer"></div>
    </div>

    <!-- 底部详情卡片 -->
    <div class="detail-card" v-if="selectedTruck">
      <el-card>
        <template #header>
          <span>车辆详情：{{ selectedTruck.truckNo }}</span>
        </template>
        <el-descriptions :column="2">
          <el-descriptions-item label="司机">{{ selectedTruck.driverName }}</el-descriptions-item>
          <el-descriptions-item label="当前位置">{{ selectedTruck.location }}</el-descriptions-item>
          <el-descriptions-item label="关联订单">{{ selectedTruck.orderCount }} 单</el-descriptions-item>
          <el-descriptions-item label="更新时间">{{ selectedTruck.updateTime }}</el-descriptions-item>
        </el-descriptions>
      </el-card>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from 'vue'
import { getTruckLocationList } from '@/api/monitor'

const mapContainer = ref(null)
const truckList = ref([])
const selectedTruck = ref(null)
const filterStatus = ref('')
let map = null
let markers = {}
let timer = null

// 初始化地图
const initMap = () => {
  map = new BMapGL.Map(mapContainer.value)
  map.centerAndZoom(new BMapGL.Point(114.305, 30.593), 10) // 默认武汉
  map.enableScrollWheelZoom(true)
}

// 渲染车辆标记
const renderMarkers = () => {
  // 清除旧标记
  Object.values(markers).forEach(marker => map.removeOverlay(marker))
  markers = {}

  // 添加新标记
  truckList.value.forEach(truck => {
    const point = new BMapGL.Point(truck.lng, truck.lat)
    const marker = new BMapGL.Marker(point)
    marker.setTitle(`${truck.truckNo} - ${truck.driverName}`)
    map.addOverlay(marker)
    markers[truck.id] = marker

    // 点击标记选中车辆
    marker.addEventListener('click', () => {
      selectedTruck.value = truck
    })
  })
}

// 刷新数据
const refresh = async () => {
  const res = await getTruckLocationList({ status: filterStatus.value })
  truckList.value = res.data
  renderMarkers()
}

// 选中车辆
const selectTruck = (truck) => {
  selectedTruck.value = truck
  // 地图定位到选中车辆
  if (markers[truck.id]) {
    map.centerAndZoom(markers[truck.id].getPosition(), 12)
  }
}

// 状态颜色
const statusTagType = (status) => {
  const map = { 0: 'info', 1: 'success', 2: 'danger', 3: 'primary' }
  return map[status] || 'info'
}

const statusText = (status) => {
  const map = { 0: '待调度', 1: '在途', 2: '异常', 3: '已到达' }
  return map[status] || '未知'
}

onMounted(() => {
  initMap()
  refresh()
  // 5秒轮询
  timer = setInterval(refresh, 5000)
})

onUnmounted(() => {
  if (timer) clearInterval(timer)
})
</script>

<style scoped lang="scss">

  height: 100%;
  display: flex;
  flex-direction: column;
}

.toolbar {
  padding: 12px;
  background: #fff;
  border-bottom: 1px solid #e4e7ed;
}

.main-content {
  flex: 1;
  display: flex;
  overflow: hidden;
}

.sidebar {

  background: #fff;
  border-right: 1px solid #e4e7ed;
  overflow-y: auto;
}

.map-container {

}

}
</style>
```

## 二、调度一张图（管理端）

### 2.1 页面定位

- **路径**：`/dispatch/board`
- **功能**：待调度订单 + 可用车辆同屏展示，一键派单
- **用户**：调度员

### 2.2 布局设计

```
┌─────────────────────────────────────────────────────────┐
│ 顶部工具栏：筛选条件 + 批量派单按钮                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    地图区域                              │
│         （订单点 + 车辆点 同屏展示）                    │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ 底部选中区：选中订单 + 选中车辆 → 派单按钮                │
└─────────────────────────────────────────────────────────┘
```

### 2.3 技术选型

| 技术 | 选型 | 说明 |
|---|---|---|
| 地图库 | 百度地图 JS API GL | 同在途监控 |
| 订单点样式 | 蓝色图钉 | 待调度订单 |
| 车辆点样式 | 绿色卡车图标 | 可用车辆 |
| 连线 | 虚线 | 选中订单到选中车辆的规划线路 |

### 2.4 完整代码模板

```vue
<template>
  <div class="page-dispatch-board">
    <!-- 顶部工具栏 -->
    <div class="toolbar">
      <el-button type="primary" :disabled="!canDispatch" @click="doDispatch">
        一键派单
      </el-button>
    </div>

    <!-- 地图区域 -->
    <div class="map-container" ref="mapContainer"></div>

    <!-- 底部选中区 -->
    <div class="selected-bar">
      <div class="selected-orders">
        <span>已选订单：{{ selectedOrders.length }} 单</span>
      </div>
      <div class="selected-truck">
        <span>已选车辆：{{ selectedTruck ? selectedTruck.truckNo : '未选择' }}</span>
      </div>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from 'vue'
import { getDispatchBoardData, dispatchAssign } from '@/api/dispatch'

const mapContainer = ref(null)
const pendingOrders = ref([])
const availableTrucks = ref([])
const selectedOrders = ref([])
const selectedTruck = ref(null)
let map = null
let orderMarkers = {}
let truckMarkers = {}
let line = null

// 初始化地图
const initMap = () => {
  map = new BMapGL.Map(mapContainer.value)
  map.centerAndZoom(new BMapGL.Point(114.305, 30.593), 10)
  map.enableScrollWheelZoom(true)
}

// 渲染订单点
const renderOrders = () => {
  Object.values(orderMarkers).forEach(marker => map.removeOverlay(marker))
  orderMarkers = {}

  pendingOrders.value.forEach(order => {
    const point = new BMapGL.Point(order.lng, order.lat)
    const marker = new BMapGL.Marker(point, {
      icon: new BMapGL.Icon('/static/order-icon.png', new BMapGL.Size(32, 32))
    })
    marker.setTitle(`${order.orderNo} - ${order.senderName}`)
    map.addOverlay(marker)
    orderMarkers[order.id] = marker

    marker.addEventListener('click', () => {
      toggleOrderSelect(order)
    })
  })
}

// 渲染车辆点
const renderTrucks = () => {
  Object.values(truckMarkers).forEach(marker => map.removeOverlay(marker))
  truckMarkers = {}

  availableTrucks.value.forEach(truck => {
    const point = new BMapGL.Point(truck.lng, truck.lat)
    const marker = new BMapGL.Marker(point, {
      icon: new BMapGL.Icon('/static/truck-icon.png', new BMapGL.Size(32, 32))
    })
    marker.setTitle(`${truck.truckNo} - ${truck.driverName}`)
    map.addOverlay(marker)
    truckMarkers[truck.id] = marker

    marker.addEventListener('click', () => {
      selectTruck(truck)
    })
  })
}

// 切换订单选中
const toggleOrderSelect = (order) => {
  const index = selectedOrders.value.findIndex(o => o.id === order.id)
  if (index > -1) {
    selectedOrders.value.splice(index, 1)
  } else {
    selectedOrders.value.push(order)
  }
  drawRouteLine()
}

// 选中车辆
const selectTruck = (truck) => {
  selectedTruck.value = truck
  drawRouteLine()
}

// 绘制规划线路
const drawRouteLine = () => {
  if (line) map.removeOverlay(line)
  if (!selectedTruck.value || selectedOrders.value.length === 0) return

  // 简单画一条从车辆到第一个订单的虚线
  const start = new BMapGL.Point(selectedTruck.value.lng, selectedTruck.value.lat)
  const end = new BMapGL.Point(selectedOrders.value[0].lng, selectedOrders.value[0].lat)
  line = new BMapGL.Polyline([start, end], {
    strokeColor: '#2B6CFF',
    strokeWeight: 3,
    strokeStyle: 'dashed'
  })
  map.addOverlay(line)
}

// 是否可以派单
const canDispatch = () => {
  return selectedOrders.value.length > 0 && selectedTruck.value
}

// 执行派单
const doDispatch = async () => {
  await dispatchAssign({
    orderIds: selectedOrders.value.map(o => o.id),
    truckId: selectedTruck.value.id
  })
  // 刷新数据
  refresh()
}

// 刷新数据
const refresh = async () => {
  const res = await getDispatchBoardData()
  pendingOrders.value = res.data.orders
  availableTrucks.value = res.data.trucks
  selectedOrders.value = []
  selectedTruck.value = null
  renderOrders()
  renderTrucks()
}

onMounted(() => {
  initMap()
  refresh()
})
</script>

<style scoped lang="scss">
.page-dispatch-board {
  height: 100%;
  display: flex;
  flex-direction: column;
}

.toolbar {
  padding: 12px;
  background: #fff;
  border-bottom: 1px solid #e4e7ed;
}

.map-container {
  flex: 1;
}

.selected-bar {
  padding: 12px;
  background: #fff;
  border-top: 1px solid #e4e7ed;
  display: flex;
  justify-content: space-between;
}
</style>
```

## 四、开发检查清单（复杂页面通用）

### 地图页通用检查

- [ ] 地图容器是否有明确的高度？（不能用 flex: 1 让地图自己撑）
- [ ] 窗口大小变化时地图是否调用了 resize()？
- [ ] 标记数量超过 100 个时是否做了聚合？
- [ ] 轮询是否在页面卸载时清除了定时器？

### 图表页通用检查

- [ ] 图表容器是否有明确的高度？
- [ ] 窗口大小变化时图表是否调用了 resize()？
- [ ] 数据为空时是否有提示？
- [ ] 大屏主题颜色是否统一（深色背景 + 浅色文字）？

### 性能注意事项

- [ ] 地图标记超过 100 个时考虑用点聚合
- [ ] 轮询频率不要太高（地图 5 秒、大屏 30 秒）
- [ ] 图表数据量大时考虑分页或聚合
- [ ] 不要在 watch 里频繁调接口
