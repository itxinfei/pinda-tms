## 二、路径说明（重要）

本目录文档内部大量以 `《某某文档》` / `《某某文档.md》` 形式互相引用，**这些引用写于它们还在顶层目录时**。移动后：

- 指向**本目录内**另一份文档的引用 → 仍然有效（同目录）。
- 指向**执行依据文档**的引用（共约 **338 处**）→ 目标现在在**上一级目录 `../`**，按文件名在顶层目录检索即可。

出于控制改动面（顶层文档间互引共 665+ 处，且本目录文档正处于大量未提交修改中），**这 338 处未逐条改写为 `../` 前缀**。需要机器解析引用时，按"同目录优先、否则回退上一级"的规则查找。

## 四、什么该进这里、什么不该

- **该进**：审查报告、修订记录、一致性核查、已被取代的调研稿、"发现问题+建议"类文档。
- **不该进**：当前需求主文档、任务卡、UI 规范、数据字典、接口契约、合规清单、排期——这些是**执行依据**，留在顶层。
- 归档一份文档前，先确认它的**结论已被 §七 决策台账或某个 D 级定案收走**；否则先补台账再归档，不要让决策定义源沉到非执行区。
