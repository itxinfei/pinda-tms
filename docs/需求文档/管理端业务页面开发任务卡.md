# 品达物流 TMS — 管理端业务页面开发任务卡（P0）

> **目的**：把《页面功能审查报告.md》发现的"业务页几乎空白"缺口，转为逐页可执行的开发任务卡（与司机/快递员/客户三端任务卡同体例）。
> **技术栈（锁定，不迁移）**：Vue 2.6.10 + Element UI 2.12 + ECharts 4.2，`pd-admin-ui` 工程。路由由**后端 `getRouter` 下发**，前端 `filterAsyncRouter` 映射 `@/views/${path}.vue`。
> **接口基线**：所有后端路径以《后端接口文档.md》为准（网关 `/api/web-manager/**`，JWT 头 `token`）。
> **优先级**：本文只收 P0（首期必做），P1/P2 见《页面功能审查报告.md》§4。

---

## 〇、开发前置约定（所有页面通用）

1. **请求封装**：统一走 `src/utils/request`（Axios），`baseURL = /api`，自动注入 `token` 头；`code!==0` 视为失败；401 清 token 跳登录（无刷新）。禁止裸 `fetch` 直连（ofpay/customer 旧实现需整改）。
2. **设计 Token**：管理端缺 Element 版 Token 文件。请在 `src/styles/` 新增 `tokens.scss`（对齐《UI设计规范与页面模板.md》精神）：主色 `$--color-primary:#1890ff`（沿用 Element 主题，勿用 `#E05635`/`#409EFF` 硬编码），所有色值/间距走变量，**禁止页面内硬编码 hex**。
3. **分页参数**：多数接口用 `page` + `pagesize`；注意 `pd-web-customer` 地址簿用 `pageSize`（驼峰）——但本卡均为 `/api/web-manager`，统一用 `pagesize`（小写）。
4. **地图能力**：在途监控/调度一张图需引入地图库（AMap/Leaflet），`package.json` 当前**无**地图依赖，需评估引入；坐标转换（BD-09→GCJ-02）后端若未提供则前端临时处理。
5. **复用现有组件**：列表用 `el-table` + `el-pagination`；表单用 `el-form` + `el-dialog`；下拉用 `el-select`（数据源走 `CommonController` 的 `common/*/simple`）。

## 一、订单管理（P0）

**后端**：`pd-web-manager` OrderController + CargoController（《后端接口文档.md》§3.1–3.2）

| 页面 | 路由 path | 功能 | 调用接口 | 验收标准 |
|---|---|---|---|---|
| 订单列表 | `pinda/order/index` | 分页查询、状态筛选、关键字搜索 | `POST /api/web-manager/order-manager/order/page` | 列表展示订单号/寄件人/状态/创建时间；分页正常；状态筛选生效 |
| 订单详情 | `pinda/order/detail` | 订单信息 + 货物明细 + 状态时间轴 | `GET /api/web-manager/order-manager/order/{id}`、`GET .../cargo?orderId=` | 展示 12 级状态机时间轴（联动 `StateTransitionValidator`）；货物明细可展开 |
| 货物编辑 | `pinda/order/cargoEdit` | 改/删货物项 | `PUT/DELETE .../cargo/{id}` | 保存后列表/详情同步 |

**注意**：订单 12 级状态机校验器已在 `pd-work` 实现，详情页时间轴须展示真实状态流转，不可硬编码。

## 四、在途监控 + 可视化调度看板（P0）

**后端**：TruckLocationController + OrderLocusController + netty 轨迹（《后端接口文档.md》§3.5–3.6、§7）

| 页面 | 路由 path | 功能 | 调用接口 | 验收标准 |
|---|---|---|---|---|
| 在途监控 | `pinda/monitor/realtime` | 实时车辆/快递员位置轮询 + 真实地图轨迹 + 明细 | `GET /api/web-manager/transfor-center/truck-place-info/{id}`、`GET /api/netty-service/trace/latest?businessId=&type=`、`GET .../trace/replay` | 引入地图库渲染真实底图；按 `businessId`+`type` 轮询 latest；replay 回放 |
| 可视化调度一张图 | `pinda/dispatch/board` | 在途一张图 + 智能推荐 + 一键派单入口 | 同上的位置接口 + TransportTask 列表 | 地图聚合展示在途任务；点击任务可下钻详情 |

**缺口提示**：
- 现有 `pinda/trace/index` 用 ECharts 折线模拟地图，本页需**替换为真实地图**（引入 AMap/Leaflet，评估依赖）。
- 轨迹**不支持按 orderId 查询**，客户/调度侧只能用 `businessId`（车辆/司机 id）查，后端改造前勿依赖订单号。
- `LocationEntity` 无 `coordSystem` 字段，坐标转换若后端未做，前端临时处理 BD-09→GCJ-02。
