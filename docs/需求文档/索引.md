## 三、关键约束速记（详见各文档）

- **后端锁死**：JDK 1.8；不升级任何依赖；安全 CVE 不处理；不引新中间件（MongoDB/HBase/RocketMQ/XXL-JOB 等为后期路线图，非 bug）。
- **网关**：现状 Zuul 1.x，不换 Gateway。
- **移动端**：uni-app（Vue3/Vite）+ uview-plus + Pinia。
- **❗接口入口（实测修正，见《联调就绪检查清单.md》§1）**：**必须走网关** `http://<host>:8760/api`；**禁止直连 `pd-web-*` 8161~8164**（`TokenAuthInterceptor` 缺 `userid` 头即 401）；JWT 头字段固定 **`token`**（非 Authorization）；登录**已存在** `POST /anno/login`（`pd-auth-server`），P0-0 只做移动端适配，严禁新建登录服务。
- **定位**：支持北斗（BDS），坐标统一转换（WGS84/GCJ02/BD09/CGCS2000）；司机强定位须 App 端。
- **视频**：司机视频接入按 GB/T 28181 / JT/T 1078 国标或云厂商 RTC SDK，不自建 RTMP 集群。
- **不对接外部厂商 API**：本项目为自营/加盟运输管理，不对接顺丰/三通一达/EDI/ERP。
- **❗环境变量（2026-10-06 实测）**：服务运行于 Docker 网 `172.21.0.x`，宿主机 `192.168.20.130`；Nacos `8848`（ns `1cb93ce4-dc0e-4730-b759-d35fd7ed93c3`，group `pinda-tms`）；网关 `8760/api`；MySQL/Redis/Kafka/RabbitMQ 均可达。
- **❗三端 BASE_URL（已确认）**：`/api/web-driver`、`/api/web-courier`、`/api/web-customer`，轨迹 `/api/netty-service/trace/latest`（或直连 `:8192`，pd-netty 无鉴权拦截器）。
- **❗联调前置（详见《联调就绪检查清单.md》§2）**：① ~~Redis 配置待重启~~ **已解除**（真根因是网关 `j2cache.config-location` 指向不存在的 `j2cache-absent.properties`，已修正并推送，无需重启）；② **已解除（2026-10-06）**：三端接口已注册进 `pd_auth.pd_auth_resource`（资源 **48 → 90 条**，新增 DRIVER/COURIER/CUSTOMER 三端角色），执行 `docs/sql/阻断C_三端接口注册与账号闭环.sql`；driver 端 `GET /user/profile` 经网关 **5/5 返回 200**。
- **UI 红线**：只用组件库、禁止裸样式；颜色/间距用设计 Token，禁止硬编码。
- **数据打通红线（详见《多端数据打通与统一领域模型》）**：三端共享同一份主记录（`Order`/`TransportOrder`/`TaskTransport`/`LocationRecord`），禁止各端私存状态副本；`Order.status`(12级) 与 `TaskTransport.status`(5级) 必须靠统一状态机双向同步；客户查轨迹只凭 `Order.id`（订单号），后端解析到 `transportTaskId`，严禁要求客户传 truckId；实时同步只用 Kafka/RabbitMQ/Netty/轮询/Spring WebSocket，不引新中间件。
