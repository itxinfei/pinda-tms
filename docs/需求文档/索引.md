## 三、关键约束速记（详见各文档）

- **后端锁死**：JDK 1.8；不升级依赖；安全 CVE 不处理；不引新中间件。
- **网关**：Zuul 1.x，不换 Gateway。
- **移动端**：uni-app（Vue3/Vite）+ uview-plus + Pinia。
- **❗接口入口**：必须走网关 `http://<host>:8760/api`；禁止直连 `pd-web-*` 8161~8164；JWT 头字段 `token`（非 Authorization）；登录 `POST /anno/login`（已存在）。
- **定位**：支持北斗（BDS），坐标统一转换（WGS84/GCJ02/BD09/CGCS2000）；司机强定位须 App 端。
- **视频**：按 GB/T 28181 / JT/T 1078 国标或云厂商 RTC SDK。
- **不对接外部厂商 API**：自营/加盟运输管理，不对接顺丰/三通一达/EDI/ERP。
- **❗环境变量**：Docker 网 `172.21.0.x`，宿主 `192.168.20.130`；Nacos `8848`（ns `1cb93ce4-dc0e-4730-b759-d35fd7ed93c3`，group `pinda-tms`）；网关 `8760/api`；MySQL/Redis/Kafka/RabbitMQ 可达。
- **❗三端 BASE_URL**：`/api/web-driver`、`/api/web-courier`、`/api/web-customer`，轨迹 `/api/netty-service/trace/latest`。
- **❗联调前置（详见《联调就绪检查清单.md》§2）**：① Redis/j2cache 已解除；② 三端接口已注册进 `pd_auth.pd_auth_resource`（资源 48→90 条，新增三端角色），driver `GET /user/profile` 经网关 5/5 返回 200。
- **UI 红线**：只用组件库、禁止裸样式；颜色/间距用设计 Token，禁止硬编码。
- **数据打通红线（详见《多端数据打通与统一领域模型》）**：三端共享同一份主记录，禁止私存副本；`Order.status`(12级) 与 `TaskTransport.status`(5级) 靠统一状态机双向同步；客户查轨迹只凭 `Order.id`。
