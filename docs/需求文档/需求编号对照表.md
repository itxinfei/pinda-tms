## 二、关系口径

| 记号 | 含义 |
|---|---|
| `1:1` | 一条 SRS ↔ 一条 FR，同一件事 |
| `1:N` | 一条 SRS 被拆成多条 FR（SRS 是粗粒度规格，FR 是可排期条目） |
| `N:1` | 多条 SRS 共用一条 FR（FR 侧欠拟合） |
| `⊂` | **部分对应**：两侧各自还含对方没有的内容，不可视为等价 |
| `SRS独有` | SRS 有规格、v2 无任何 FR 承接 → **排期盲区** |
| `FR独有` | v2 有 FR、SRS 第 6 章无编号条目 → **规格盲区** |
